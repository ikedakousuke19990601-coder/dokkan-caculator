# ドカバト 被ダメージ計算ツール

敵から受けるダメージを計算し、自分のキャラがどのくらい受けるかをすぐ確認できる Web アプリです。

**公開URL: https://dokkan-caculator.vercel.app**

> 結果は、コミュニティで知られている計算式に基づく**目安**です。公式の計算式は公開されていないため、実際のダメージとずれることがあります。

### このアプリが解決すること

スマホゲーム「ドラゴンボールZ ドッカンバトル」では、敵の攻撃でどれだけダメージを受けるかが、
DEF の上昇効果・軽減率・属性ガードなど10個近い要素の掛け合わせで決まります。
これまでは攻略サイトの計算式を見ながら電卓で計算する必要がありました。
このツールは、ゲーム画面に出ている数値を入力するだけで、被ダメージと「ダメージ0にできる敵ATKの上限」をその場で表示します。

### 1. 計算ロジックと UI を分けた設計

```
components/（表示だけ） → hooks/useCalcInput（状態管理） → logic/（純粋関数で計算）
                                          └→ storage/（localStorage への保存・復元）
```

- 計算は `src/logic/` に React や DOM に依存しない純粋関数として置き、UI を通さずにテストできるようにしました。
- 端数処理（途中は切り捨て、最終値は四捨五入）は `rounding.ts` の1か所にまとめています。
  ダメージ側の端数処理は公式に公開されておらず仮の仕様なので、実機で確かめて方針が変わっても、このファイルだけ直せば済むようにしています。

### 2. 数値計算の正確さへの配慮

- **浮動小数点の誤差**: `100 × 1.15 = 114.99999999999999` を切り捨てると 114 になってしまうため、有効桁数12桁で丸めて誤差を取り除いてから端数処理をしています。
- **`NaN` / `Infinity` を画面に出さない**: 全角数字・カンマ・`%` を正規化し、`1e3` や `0x10` のように `Number()` なら通ってしまう表記ははじきます。0除算になる -100% もエラーとして表示します。
- **完封できる敵ATKの上限**: 敵ATKを上げると被ダメージは減らない（単調に増える）性質を使い、倍々の探索と二分探索で境目を求めています。
  計算式の逆算を別に書くと端数処理がずれるおそれがあるため、通常のダメージ計算をそのまま呼んでいます。

### 3. テスト戦略

- 計算ロジックはテスト駆動で実装しました。
- 受け入れテスト（`acceptance.test.ts`）では、期待値を手計算で出し、その計算過程をテストケースに残しています。仕様の根拠を後から追えるようにするためです。
- 0・負数・空欄・-100%・ダメージが0で止まるケースなど、境界値を必ず含めています。

### 4. 壊れない保存処理

- localStorage から読んだ値は信用せず、項目ごとに検証してから使います。1項目が壊れていても、ほかの項目は復元できます。
- 保存できない環境（プライベートブラウズなど）でも、既定値で起動します。
- 入力のたびに書き込まないよう、入力が止まってから保存しています。外部へのデータ送信はしていません。

## 使い方

1. **画面のDEF** に、戦闘中のゲーム画面で確認した DEF を入力します。リーダースキル・リンクスキル・今のパッシブ・フィールド効果は、この値にすでに入っています。
2. **敵ATK** に、攻略サイトなどで調べた敵の ATK を入力します。
3. 結果欄に **乱数なし** と **最大乱数** の2つのダメージが表示されます。計算ボタンはなく、入力するとすぐ更新されます。
   結果欄の下には、**完封できる敵ATKの上限**（そのATKまでならダメージ0）も表示されます。敵ATKを入力しなくても、画面のDEFがあれば見られます。

必要に応じて、次の項目も入力できます。

| 項目                           | 内容                                                                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| これから上がる効果             | 区分（パッシブ（足し算）／パッシブ（掛け算）／サポートメモリー・アイテム／アクティブスキル／必殺技の追加効果）と、上がる％。「＋ 効果を追加」で行を増やせます |
| 詳細（反映済みの％）           | 画面のDEFにすでに入っている、同じ区分の効果の％。通常は 0 のままで大丈夫です                                                                                  |
| ダメージ軽減率（％）           | 初期値 0                                                                                                                                                      |
| 属性防御係数A（属性ガード）    | なし(1.0) / 0.9 / 0.8 / 0.7 / 0.6。全属性ガードがオンの間は 0.8 に固定されます                                                                                |
| 属性防御係数B（全属性ガード）  | オンで B=0.5、同時に A=0.8（敵ATK×0.8 → DEFを引く → ×0.5 の2段階）                                                                                            |
| フィールド補正（最終ダメージ） | 初期値 1                                                                                                                                                      |

入力した内容はブラウザ内（localStorage）に保存され、次に開いたときに復元されます。外部には送信しません。

## 計算式

```
現在DEF = 画面のDEF × Π(区分ごと) (1 + 反映済み% + 追加%の合計) ÷ (1 + 反映済み%)
基本ダメージ(r) = { 敵ATK × r × A × (1 − 軽減率) − 現在DEF } × B × フィールド補正
結果(r) = max(0, 基本ダメージ(r))
```

- 乱数なしは r = 1.00、最大乱数は r = 1.03 で計算します。
- 同じ区分の行が複数あるときは、％を足してから1回だけ掛けます。
- 途中の計算は都度切り捨て、最終値のみ四捨五入します。ダメージ側の端数処理は未確認のため、仮の仕様です。

属性相性（有利・不利）、見切り、気力補正、キャラ・パッシブのデータベース、受けたダメージから敵ATKを逆算する機能。

## 対応ブラウザ

最新の Chrome・Safari。オフラインでは使えません。

## 開発

React + Vite + TypeScript + Tailwind CSS で作った、サーバーのない静的な Web アプリです。要件は [docs/spec.md](docs/spec.md)、設計は [docs/architecture.md](docs/architecture.md) にあります。

```sh
npm install
npm run dev            # 開発サーバー（http://localhost:5173）
npm test               # テスト
npm run test:coverage  # テスト＋カバレッジ（src/logic/ は 100% 必須）
npm run lint           # Lint（oxlint）
npm run format         # 整形（Prettier）
npm run build          # 本番ビルド（dist/）
```

`main` ブランチに push すると、Vercel に自動でデプロイされます。
